# PD5_Calculadora-Daus-3D
Aplicació web interactiva dissenyada per treballar el càlcul mental (suma, multiplicació i resta) i la probabilitat mitjançant daus 3D (D6, D8 i D12) i la figura del robot comodí **🤖 PCMAT**. És un recurs ideal per a aules heterogènies i atenció a la diversitat (NESE). Creat per Aurora Pelejà (Mentoria PCMAT).
