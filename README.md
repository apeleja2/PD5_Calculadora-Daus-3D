# 🎲 Daus 3D i Calculadora PCMAT

Eina web interactiva 3D per treballar el càlcul mental (suma, multiplicació i resta) i la probabilitat a l'aula, adaptada per a entorns NESE i desenvolupada en el marc de la **Mentoria PCMAT (XTEC)**.

---

## 🌟 Característiques

* **Daus 3D Reals**: Modelatge de **D6**, **D8** i **D12** amb Three.js (materials blancs satinats i text fosc d'alt contrast).
* **Comodí 🤖 PCMAT**: Si apareix la cara del robot, la calculadora l'identifica i l'exclou automàticament de l'operació.
* **Calculadora Adaptada**:
  * ➕ **Suma**
  * ✖️ **Multiplicació**
  * ➖ **Resta (Max - Min)**: Ordena els valors de major a menor ($V_{max} - V_2 - \dots - V_{min}$) per facilitar el càlcul visual.
* **Alta Accessibilitat**: Dissenyat segons les pautes DUA (botons grans, alt contrast i interfície neta per a PDI).

---

## 🚀 Com fer-lo servir

1. Descarrega el fitxer `index.html`.
2. Obre'l directament en qualsevol navegador (Chrome, Firefox, Safari, Edge) o publica'l a **GitHub Pages**.
